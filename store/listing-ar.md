# Arabic store listing (Chrome Web Store + AMO)

Both stores let you give each language its own listing text, and Arabic
searches have far fewer competitors than English ones. The manifest's
`_locales/ar` name and short description are already set. The long text
below goes into the store dashboards by hand.

- **Chrome Web Store:** Developer Dashboard → item → **Store listing** →
  language selector at the top → add **Arabic (العربية)** → paste the
  description.
- **AMO:** Edit listing → **Describe Add-on** → locale picker → **العربية** →
  paste the summary (250 characters max) and the description.

Words Arabic users search for, covered below: عكس قائمة التشغيل، من الأقدم
إلى الأحدث، خلط عشوائي، ترتيب، مدة قائمة التشغيل، المشاهدة لاحقًا، يوتيوب.

---

## Summary (AMO, ≤ 250 characters)

اعكس قائمة تشغيل يوتيوب وشاهدها من الأقدم إلى الأحدث، أو اخلطها عشوائيًا، أو رتّبها حسب العنوان والمدة والقناة. اعرف المدة الكاملة والمتبقية، وأنشئ قوائمك الخاصة — مجانًا، بدون تسجيل، وبخصوصية تامة.

## Description (both stores)

**شاهد قوائم تشغيل يوتيوب بالترتيب الذي تريده أنت.**

دورة تعليمية رُفعت بالمقلوب؟ مسلسل تريد مشاهدته من الحلقة الأولى؟ قائمة "المشاهدة لاحقًا" تكدّست؟ أدوات قائمة التشغيل تضيف شريطًا صغيرًا أعلى قائمة التشغيل في يوتيوب يمنحك التحكم الكامل:

⮃ **عكس قائمة التشغيل** — شغّلها من الأخير إلى الأول، أي من الأقدم إلى الأحدث. يُحفظ الاختيار لكل قائمة.

⤮ **خلط عشوائي حقيقي** — ترتيب عشوائي واحد يبقى ثابتًا، فلا يتكرر الفيديو نفسه.

⇅ **الفرز** — حسب العنوان (أ←ي أو العكس)، أو المدة (الأقصر أو الأطول أولًا)، أو القناة، أو غير المُشاهَد أولًا.

⠿ **إعادة الترتيب بالسحب والإفلات** — مع زرّي النقل إلى الأعلى والأسفل.

⚡ **تحميل الكل** — يحمّل جميع فيديوهات القوائم الطويلة بنقرة واحدة، حتى يشمل العكس والخلط والفرز القائمة كاملة.

⏱️ **حاسبة المدة** — المدة الكلية، وما شاهدته، وما تبقّى، والوقت المتبقي بسرعة ‎1.25x و‎1.5x و‎2x.

＋ **قوائم تشغيل محلية** — أضف أي فيديو إلى قائمة تنشئها بنفسك، محفوظة في متصفحك فقط.

🎵 **حفظ اللقطات** — احفظ ترتيبك المخصص باسم ووسوم، وأعد تشغيله متى شئت.

⏯️ **المتابعة من حيث توقفت** — يعيدك إلى آخر فيديو ودقيقة في كل قائمة.

⌨️ **اختصارات لوحة المفاتيح** — Alt+Shift+O للعكس، وAlt+Shift+S للخلط، وAlt+Shift+K للإضافة إلى قائمتك، وAlt+Shift+L لتحميل الكل. ويمكنك تغييرها.

🔁 **التكرار، شارات المشاهدة، تخطّي المُشاهَد، وإيقاف التشغيل التلقائي.**

📤 **نسخ احتياطي** — صدّر قوائمك وإعداداتك إلى ملف واستوردها على أي جهاز.

**🔒 خصوصيتك أولًا**
- لا تسجيل دخول ولا حساب Google.
- لا يتصل بخوادم يوتيوب أو أي جهة خارجية.
- كل البيانات تبقى في متصفحك فقط، ولا يُجمع أي شيء.
