# v3.0.0 Design — YouTube Playlist Tools

Date: 2026-06-12
Status: implementing (autonomous session; user requested "version 3 that has all we need as a YouTube viewer")

## Context

AMO listing (queried 2026-06-12 via API): 17 average daily users, 34 weekly
downloads, 0 ratings, v2.0.4 public. Young extension, growing — v3 focuses on
making the saved-playlists feature actually permanent (import/export + apply
order on play), fixing silent correctness bugs, and cutting the always-on
MutationObserver cost.

## Bug fixes

1. **Watched never marked in reverse/shuffle mode** (`src/playback.js`)
   `onTimeUpdate` pre-empts navigation 0.35 s before the end, so `ended` never
   fires and `markAsWatched` never runs while a mode is active.
   Fix: mark the current video watched inside `onTimeUpdate` before `stepTo`.

2. **Playing a saved snapshot does not apply its order** (`src/panel.js`,
   `popup/popup.js`)
   Play only navigates to the first video; the snapshot order is never written
   to `customOrder:<listId>`. Fix: write the snapshot order (and clear
   reverse/shuffle flags) to storage before navigating, in both the in-page
   panel and the popup. This is what makes saved lists "permanent playlists".

3. **End of reverse/custom order falls through to YouTube autoplay**
   (`src/playback.js`) — when `nextIndexInMode` returns `null` we set
   `endHandled` and do nothing, so YouTube advances forward. Fix: pause the
   video at the end of the order (unless loop mode, below).

4. **Popup shows Save section on `/playlist` browse pages** where the content
   script then errors. Fix: require `/watch` + `list=` in the URL check.

5. **Watched stored by playlist index** — indices shift when the playlist
   changes, badges drift to wrong videos. Fix: store watched as videoId
   strings; migrate legacy numeric arrays on load (map index→videoId via the
   loaded sidebar items; unmappable entries dropped).

## Performance

6. `content.js` MutationObserver fires on every childList mutation in the
   whole document and runs `readItems()` + style writes each time. Fix:
   debounce the callback (trailing ~150 ms) and early-exit when there is
   nothing to do (toolbar present, no active mode, reorder off, no badges).

## Features

7. **Export / Import saved playlists** (popup): Export downloads
   `playlist-tools-backup-YYYY-MM-DD.json`
   `{ schema:"ryp-saved-playlists", schemaVersion:1, exportedAt, playlists:[…] }`.
   Import opens a file picker, validates shape, merges by `id` (skips exact
   duplicates), regenerates colliding ids, shows imported/skipped count.
   Buttons live in the popup header next to settings; i18n en/fr/ar.

8. **Loop playlist order** (setting, default off): when the active order ends,
   wrap to its first item instead of stopping. Guard: with auto-skip on and
   everything watched, stop instead of spinning.

9. **Rate-us link** in popup footer (0 reviews today; reviews drive AMO
   discovery).

## Release plumbing

## Out of scope

(snapshots already store videoId per entry; order keys stay indices),
